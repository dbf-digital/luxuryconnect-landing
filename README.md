# LuxuryConnect — Landing Page

Landing page for LuxuryConnect.fr, an AI sales agent SaaS for B2B premium founders.

Single-file static HTML. Deployed via Coolify as a Static Site.

## Domains
- luxuryconnect.fr (apex)
- www.luxuryconnect.fr

## Stack
- HTML/CSS only (no JS framework, no build step)
- Google Fonts: Fraunces (display) + Inter (body)
- Deploys via Coolify webhook on push to main
